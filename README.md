# Robot Tout-Terrain

## 1. Présentation
Projet de groupe visant à concevoir et développer un robot tout-terrain capable de se déplacer sur différents types de surfaces.

## 2. Objectifs
- Concevoir le châssis et le système de déplacement.
- Développer le système électronique et embarqué.
- Intégrer les capteurs et les actionneurs.
- Tester les performances du robot sur différents terrains.

## 3. Architecture du système
- **Mecanique :** châssis, roues et supports.
- **Electronique :** carte de commande, alimentation et drivers moteurs.
- **Firmware :** commande des moteurs, lecture des capteurs et logique de déplacement.

## 4. Organisation du dépôt
- `hardware/` : schémas et conception électronique.
- `firmware/` : code embarqué.
- `mechanical/` : conception mécanique et fichiers 3D.
- `docs/` : documentation technique.
- `media/` : photos et vidéos.
